О проекте StartupEval

«Интеллектуальный сайт для оценки перспективных стартап-идей» — проект по дисциплине «Информационно-коммуникационные технологии», Университет Нархоз.

Цель проекта

Начинающие предприниматели и студенческие команды часто переоценивают свои идеи: вкладывают месяцы в продукт, который никто не ждёт. StartupEval даёт быстрый структурированный взгляд со стороны — по шести критериям и с понятными рекомендациями, что проверить в первую очередь.

Задача проекта — не вынести окончательный вердикт, а помочь задать правильные вопросы до запуска MVP.

Технологии

  • AI-модель: Google Gemini через серверную функцию с системным промптом и строгим JSON-контрактом.
  • Хостинг: Vercel — статика и serverless-функции в одном проекте.
  • Визуализация: Chart.js 4.4.1 (радарная и столбчатые диаграммы).
  • Фронтенд: семантический HTML5, CSS-переменные, vanilla JS без сборщиков.
  • Данные: JSON-файлы в репозитории, без базы данных и без хранения персональных данных.

Как устроена оценка

  1. Пользователь заполняет форму: название, описание, аудитория, монетизация, регион.
  2. Браузер отправляет POST-запрос на /api/evaluate.
  3. Серверная функция подставляет системный промпт и вызывает модель с требованием вернуть JSON.
  4. Ответ проверяется по структуре: шесть критериев, балл — целое число от 1 до 10.
  5. Итоговый балл считает браузер по фиксированным весам — модель не может его «подкрутить».
  6. Если API недоступен, сайт показывает сохранённый демо-пример и честно об этом сообщает.

Ограничения и этика

  • ИИ может ошибаться. Модель не проверяет факты и может уверенно выдавать неверные выводы.
  • Оценка не заменяет экспертов. Это инструмент первичного скрининга, а не инвестиционное решение и не Due Diligence.
  • Данные пользователя не сохраняются. Описание идеи уходит в API модели для генерации ответа и не записывается в базу.
  • Нет гарантий успеха. Высокий балл не означает, что проект заработает; низкий — что он обречён.
  • Возможны искажения. Оценка зависит от полноты описания и может быть предвзятой к знакомым модели формулировкам.
