Здесь лежат изображения проекта.

Ожидаемые файлы:
- hero.jpg — AI-иллюстрация для hero-блока на главной (рекомендуется 1600×1200, до 400 КБ).
- pitch-poster.jpg — постер для видео на главной (16:9, например 1280×720).
- crit-1.jpg … crit-6.jpg — иллюстрации критериев (необязательно; сейчас используются градиентные заглушки).

Пока файлов нет, сайт показывает аккуратные градиентные заглушки:
common.js скрывает «битые» изображения, если файл не найден.

После добавления файлов удалите подписи-заглушки:
- в index.html — <p class="video-note"> внутри блока .video-wrap;
- в hero-блоке — <figcaption class="media-note">;
- в index.html — подписи в карточках критериев (.criterion-thumb).
